# Induztek — Aplicación Android

## Descripción

MVP móvil para digitalizar el registro de pruebas eléctricas realizadas en terreno por Induztek Ingeniería SpA. La aplicación busca facilitar el registro de mediciones y la consulta del historial de pruebas de los equipos.

## Objetivo

Reducir la doble digitación y el tiempo necesario para preparar los protocolos, y facilitar la comparación de resultados anteriores.

## Tecnologías

- Kotlin
- Android Studio
- Jetpack Compose
- Material Design 3
- Arquitectura MVVM
- Room/SQLite para almacenamiento local
